## 2. 开始之前必须知道的五件事

这五条全部是刚刚读你**真实的** `state.json` 得到的，不是猜的。不先看，第 5、9 节会当场卡住。

### ⚠️ 一、你的题库里现在**只有 1 道题**，换题验证会当场无题可换

```
questions: 1   →  p1-home-001 · Part 1 · Home · "What do you like most about your home?"
sessions:  0
targets:   1
issues:    0
```

换题验证的规则是**只在同一个 Part 内换、且排除原题本身**（`TransferQuestionPolicy`）。
题库里只有这一道 Part 1，所以你一走到第 9 节就会撞上空状态：

> 题库里没有第二道 Part 1 的题可以换
> 换题验证只在同一个 Part 内换——Part 1 要短、Part 3 要展开，同一个目标在两者里的达成标准根本不一样。下一步：到「训练题库」导入更多题目，回到这里就能换一道再练一趟。

**这个空状态本身是对的**（它给了说明 + 下一步 + 按钮，值得你顺手验一眼），
但它会让第 9 节——**本阶段真正的交付物**——一步都走不下去。

**所以第 3 节的准备工作里加了一条：先导入你的 PDF 题库。** 没有这一步，Phase 6 只能验一半。

### ⚠️ 二、你现在那条复训目标的**来源练习记录已经不在了**

```
targets[0] = { id: "grammar_sentence_control",
               label: "先说完整主干句，再补充细节",
               status: "需要优先练习",
               evidence: [],
               sourceSessionId: "2026-08-05T14:30:44Z" }
sessions = []            ← 这个 sourceSessionId 指向的记录不存在
```

后果（都是**设计如此**，不是缺陷）：

- 复训中心里这一条会带着一句中文说明：「这个目标来自的那次练习记录已经不在了，找不回当时练的是哪道题。下一步：仍然可以带着这个目标从题库里自己挑一道题练；「重答原题」这一条则用不了了。」
- 它那颗按钮写的是「**挑一道题带着这个目标练**」，**不是**计划 Step 4 里写的「带着本题进入复训」
- 它的「当时说的：」那一行不会出现（`evidence` 是空数组）

**这一条正好白送你一个验收项**：完成标准第 9 条要求「源题找不到时有中文说明与下一步，
那一条不会从列表里消失」。你不用人为破坏任何数据，打开页面就能验（第 6 节）。

**但计划 Step 4 那条主线（回看证据 → 重答原题）必须用一个「来源记录还在」的新目标来走**，
所以第 5 节要真练一场普通练习先造一个出来。

计划 Step 2 写「练完确认『重训目标』数字从 0 变正」。你盘上已经有 1 条，

## 7. 【计划 Step 4】走完「带着本题进入复训」——**撤掉提示的肉眼验法**

**这一节是本阶段的成败判据之一，也是自动化最够不着的一节。**

源码守卫已经拦住了「材料被搬到不该出现的那一屏」（第 1 节表里那条结构性测试）。
它拦不住的有两种，而这两种在屏幕上一模一样地严重：

1. **条件写反或永远为真**——`if step.showsModelAnswer` 还在，但那个属性的实现被改坏了；
2. **界面没刷新**——步骤切了，上一屏的卡片留在原地（SwiftUI 的状态更新出岔时会这样）。

两种在 `swift test` 里都是全绿。**只有你盯着屏幕能发现。**

### 7.1 第一步：回看证据

- [ ] 在复训中心点**新目标**那条的「带着本题进入复训」

顶部应当出现三格进度：`1 回看证据`（当前，紫色）/ `2 重答原题` / `3 撤掉提示，开口说`。

- [ ] **把正文区从头滚到底**（sheet 是固定 660×620 的窗口，一屏装不下），逐项确认：

| 应当出现的卡片标题 | 缺了的话 |
|---|---|
| 「第 1 步 · 回看证据」+ 说明 | 缺了就是缺陷 |
| 「**本次唯一目标**」 | 缺了就是缺陷。里面那句话记下来，第 8 节要拿它去 ChatGPT 窗口里逐字核 |
| 「当时说的原话」 | 目标的 `evidence` 为空时**不显示**，属正常 |
| 「当时的完整原答」 | 复盘里 `answer_upgrades` 为空时不显示，但**必须有一张警示卡说清为什么**：「这份复盘里没有可对照的原答…」 |
| 「复盘说改了什么」 | 同上 |
| 「**复盘给的高分版**」 | 这是第 7.2 节要盯的主角。**把里面的一句英文抄下来或截图** |
| 「逐字稿里你说过的话」 | 没有的话应当显示那句 hint（见第 2 节第四条与第 13 节） |

- [ ] **缺了哪一样，有没有说清楚？** 计划 Step 4 第 2 点问的就是这个。
      少一块内容不要紧，**少了还不说才是缺陷**。
- [ ] **截一张图**（⌘⇧4）附进报告——它是第 7.2 节的对照物。

### 7.2 第二步：**撤掉提示**（本节核心）

- [ ] 点「**重答这道题**」
- [ ] **先别点「开始练习」。** 把这一屏**从头滚到底**，慢慢看。只看第一屏不算数。

**下面这五个标题，一个都不许出现：**

```
当时说的原话
当时的完整原答
复盘说改了什么
复盘给的高分版          ← 头号
逐字稿里你说过的话
```

**这一屏上应当只剩三样：**

```
第 2 步 · 重答原题          （说明卡）
本次唯一目标                （必须还在——撤掉的是答案，不是目标）
这一趟练的是 · Part N · 话题 （题目卡：题干 + 追问）
```

**一个额外的、更好用的判别法：** 这一屏上**允许出现的英文只有题干和追问**。
除此之外任何一段英文长句都可疑——高分版和原答都是英文，在满屏中文里很扎眼。

## 15. 出事了怎么退回去

- **训练数据被改坏 / 误删** → 用第 3 节备份的那份文件夹整个换回去（App 要先 ⌘Q 退出）
- **某个目标被误标成「不用再练」** → 复训中心底部「已经不用再练的目标」里点「重新放回待复训」，
  不用改文件
- **想在不碰真实数据的情况下折腾** → 全程加 `IELTS_SPEAKING_DATA_DIR=/tmp/某个目录` 启动，
  **每次都要先 ⌘Q 完全退出**，否则只是把已经在跑的那个切到前台，换的目录不生效：
  ```bash
  IELTS_SPEAKING_DATA_DIR=/tmp/ielts-phase6 open ".build/IELTS Speaking Coach.app"
  ```
  **注意：辅助功能授权是按 bundle id 记的，换数据目录不会换权限**，所以复训照样能真的驱动 ChatGPT
- **ChatGPT 会话被弄乱** → 每场练习都是新建会话，删掉那条会话不影响本工具的任何数据
