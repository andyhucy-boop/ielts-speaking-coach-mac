## 二、夜里抓到并修掉的，值得你知道的几件

**逐字稿的顺序会被搞乱。** ChatGPT 的对话区会随内容变长滚动，早先的消息滚出可视区后
AX 树里就读不到了——「这次只读到最新一条」是常态。而那种情况下新消息会被插到**最前面**。
用户回看会看到考官的第三个问题排在第一个前面，**没有任何报错**。

**错题的「出现次数」会重复累加。** 同一份复盘归档两次（重试、补录都会），
数字就多加一遍，`lastSeenAt` 还会被覆盖。这个数字是「你的毛病有没有变少」的全部依据——
虚高的后果不是显示错一个数，是**让你以为自己在变差，而实际可能正在变好**。
已修，并且加了读盘迁移：**你现有 `state.json` 里已经虚高的数字会自动算回来，你什么都不用做。**

**打包脚本的两个闸门都形同虚设。** 「✅ 已生成」是在检查签名之前打印的，
而且检查那行结尾是 `|| true`。证书哪天到期或被重新生成，辅助功能授权会失效，
而你唯一的线索是 macOS 又来要一次权限。

**`make-icon.sh` 在任何 UTF-8 locale 下必然崩。** `echo "✅ 已生成 $ICNS（10 个尺寸齐全）"`——
bash 会把全角括号的字节当成变量名的一部分。这台机器的 shell 恰好是 C locale 所以一直是绿的，
**换个终端就红**。

**PDF 题库提取核对过了**：话题 59/59、cue card 99/99、1264 道题 id 全唯一、垃圾 0 条。
实现者自己还发现并修了两处真实提取错误。

## 三、需要你亲自做的（程序绕不过去）

按建议顺序：

### 1. 给 App 授辅助功能权限（一次性，5 分钟）

```bash
cd ~/Projects/ielts-speaking-coach-mac && ./scripts/build-app.sh && open ".build/IELTS Speaking Coach.app"
```

首次打开会停在引导页。**系统设置 › 隐私与安全性 › 辅助功能 → 把
`IELTS Speaking Coach` 加进去并勾选 → 回 App 点「重新检查」。**

然后**再跑一次 `build-app.sh`，不重新授权直接打开**——如果又要求授权，
说明打包方案有问题，停下来告诉我。这一条是 Phase 3 最关键的验收。

### 2. 导入你的 PDF 题库，然后真练一场（30 分钟）

**把终端关掉**，只用 App。这是整个 Phase 3 + 4 的成败判据：

- 数一下从双击图标到 ChatGPT 开口，一共点了几次（目标 ≤ 3）
- 启动语音那 9 秒里，界面有没有一直在说它在干什么
- 练完点「我练完了」，看错题本 / 词汇本 / 重训目标三处数字有没有从 0 变正

### 3. 逐条核对逐字稿（这一步最重要，只有你能做）

打开训练记录，对着 ChatGPT 窗口逐条核：

- 考官问过的每一个问题都在吗？
- **顺序对吗？**
- 分得清哪句是考官说的、哪句是你说的吗？

**说话人判别在语音会话里成不成立，至今没有任何人验证过。** spec 只记录了普通聊天界面的
复制按钮，语音会话的实时字幕带不带它们是未知的。设计上「判不出就记 unknown，绝不猜」——
所以内容和顺序照样完整，最坏情况只是分不清谁说的。这条大概率需要一轮调整，
`docs/phase4-acceptance-checklist.md` 里有「什么现象改哪个文件」的对照表。

### 4. 麦克风权限 + 插拔耳机（15 分钟）

打开「保存我的回答录音」时点「允许」。然后：
**戴耳机说 30 秒 → 拔掉说 30 秒 → 插回说 30 秒**，确认只有一条录音、三段都在、总时长约 90 秒。

这是 Phase 5 最高风险的一条，假实现测不了真实设备切换的时序。
详见 `docs/phase5-acceptance-checklist.md`。

### 5. 看着顺不顺手

这个只有你有。特别是：**哪里让你不想用。**

## 四、我替你做的决策，需要你复核

全部在 `docs/superpowers/DECISIONS-2026-08-06.md`，每条都标了改主意的成本。
其中两条值得重点看：

- **会话编号统一成 `YYYY-MM-DD-NNN`，但校验同时接受旧的 ISO8601 形状。**
  你现有 `state.json` 里已经有旧格式的 id，拒绝它等于让已有练习记录全部失效。
- **复盘取回失败后的补救做进了界面。** 原本唯一途径是终端跑 `coach reimport`，
  而成品标准第 2 条是「全程不需要打开终端」——出错恰恰是最需要它成立的时候。
