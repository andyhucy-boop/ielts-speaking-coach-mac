## 0. 这份文件是什么

Task 11 是 Phase 5 唯一**不能由子代理代劳**的任务。它要做三件任何自动化都替不了的事：

1. **在系统弹窗上点「允许」**——那个对话框不属于本应用，脚本点不了、AX 也点不了，

- **会不会动到你的数据**：会。第 9 节要真删一个录音文件，第 10 节要把文件移走。**先按第 3 节做备份。**

## 4. 【计划 Step 1】授予麦克风权限——**只有你能做**

1. [ ] 按 `⌘,` 打开设置窗口。看到的应当是：
       - 区块标题 `01 RECORDING` / **练习录音**
       - 一个开关：**保存我的回答录音**（此时应当是**关**的）
       - 下面三段小字，第二段必须是
         「本工具只录你自己的麦克风，不录 ChatGPT 的声音。考官问了什么，看训练记录里的逐字稿。」
       - 第三段应当是「录音默认关闭。打开之后才会申请麦克风权限。」
       - 区块标题 `02 DISK USAGE` / **录音占了多少地方**，内容应当是
         「还没有录音。开启「保存我的回答录音」之后，你练习时说的话会存在这里。」
2. [ ] **拨开开关。**
3. [ ] **系统会弹出一个对话框问「IELTS Speaking Coach 想访问麦克风」——请点「允许」。**

| 看什么 | 判据 |
|---|---|
| 弹窗里的用途说明 | 必须是中文那一句：「开启「保存我的回答录音」后，用于录下你练习时的回答，便于回听。录音只存在本机，可随时删除。」**若弹窗里是英文的系统默认文案，说明 Info.plist 那个键没进包，停下报告** |
| 点「允许」之后 | 开关变成**开** |
| 页面上出现的那段提示 | 应当是「已开启。从下一次练习开始，你的回答会录在本机的 recordings 目录里，只存在这台电脑上，不上传任何地方，随时可以逐条删除。**下一步：建议戴耳机练——用外放的话，麦克风会把 ChatGPT 的声音也一起录进去。**」 |
| 同意时间 | 第三段小字变成「你在 2026-08-07T…Z 同意保存录音。」——**时间必须是刚才那一刻** |

**失败怎么判：**

- **点了「允许」但开关没变成开** → 落盘出了问题。看页面上有没有一段「设置没能保存：…」，
  有就把它一字不差抄下来；没有就是静默失败，**这是严重缺陷，立刻停下报告**。
- **根本没弹窗，直接显示「麦克风权限被拒绝过…」** → 这台机器上这个 bundle id 之前被拒过。
  去「系统设置 › 隐私与安全性 › 麦克风」里看有没有本应用、是不是关着的，打开它，回来重拨一次开关。

## 5. 【计划 Step 2】验证「被拒」这条路走得通（强烈建议做）

**这一步验的是「用户会不会卡死在这里」。** macOS 一个 App 一辈子只为麦克风弹一次系统对话框，
拒过之后再点开关什么都不会发生——没有一条能点的出路，用户就只能对着一个永远不出现的弹窗干等。

1. [ ] 到「系统设置 › 隐私与安全性 › 麦克风」，**把本应用关掉**。
       - 系统可能提示「必须退出并重新打开 App 才生效」。**若提示了就照做，这不是缺陷。**
2. [ ] 回到 App，按 `⌘,`。**若设置窗口原本就开着，先把它关掉再按一次 ⌘,**——
       这一页是在窗口出现时（`onAppear`）才重读一次权限的，一直开着的窗口显示的是旧值。
3. [ ] 拨一下开关。

| 看什么 | 判据 |
|---|---|
| 开关 | **必须停在「关」。** 显示成「开」却什么都不录，是本项目最不能接受的那种失败 |
| 提示原话 | 「麦克风权限被拒绝过，系统不会再弹第二次对话框。下一步：打开「系统设置 › 隐私与安全性 › 麦克风」，把「IELTS Speaking Coach」那一项打开，然后回到这里再点一次开关。」 |
| 出路卡片 | 应当出现一张卡片，标题「**麦克风权限不在本应用手里**」（`mic.slash` 图标，警示色），里面重复那段引导，底下一颗「**打开系统设置**」按钮 |
| 那颗按钮 | 点了要**真的跳到麦克风那一页**。跳不过去时应当显示「没能替你打开系统设置（这台电脑不认这个设置页链接）。下一步：自己打开…」——**绝不能是一颗点了没反应的按钮** |
| 同意时间那一句 | 因为你在第 4 节已经同意过，这里应当变成「你在 … 同意保存录音，**但麦克风权限现在不在本应用手里，所以上面的开关停在「关」，练习时不会录音（已经录下的录音都还在）**。…」——不把这个错位说破的话，你只会觉得「我明明开过，怎么自己关了」 |

**要写进报告的主观判断：** 这段引导，**一个不懂技术的人能不能照着做出来？**（成品标准第 8 条）

4. [ ] **把权限打开回来**（「系统设置 › 隐私与安全性 › 麦克风」里把本应用重新打开；
       **若系统要求退出并重开 App，就照做**），然后**按 `⌘,` 重新打开设置窗口**
       （原本开着的先关掉再按一次），确认开关**自己**回到「开」——**不要再拨它**。

> **为什么不能拨：** 第 3 步那一次「被拒时拨开关」只是把界面上的开关按在「关」位，
> **没有写盘**（代码里权限不到手就直接返回，不碰 `state.json`），所以磁盘上你在第 4 节给的那次同意
> 一直好好留着。权限一还回来，设置窗口出现的那一刻重读一次，开关**自己就是「开」**。
> 这时候再去拨一下，拨的是一个**已经在「开」位**的开关：结果是把录音关掉、
> 连那次同意时间戳一起清空，屏幕上还会跳出「已关掉录音…」。
> **那不是缺陷，是多拨了一下。** 真想验「关掉再打开」，第 11 节专门验它。

## 6. 【计划 Step 3】录一场真的练习

**终端保持关闭，只用界面**（成品标准第 2 条靠这个姿势验）。

- [ ] 确认设置窗口里开关是**开**的，然后把设置窗口关掉
- [ ] **戴上耳机**（这一场用耳机；外放那一次放在第 7 节）
- [ ] 到「今日训练」页点「开始」，正常练 3–5 分钟，然后点「我练完了」

| 看什么 | 判据 |
|---|---|
| **录音指示** | 练习面板上应当出现一个红色的 `record.circle` 图标 + 「**正在录音**」四个字。**必须是静止的**——不许有呼吸闪烁（你这时正要开口说英语，一个一直在动的红点是最容易让人分心的东西） |
| **出现的时机** | 它是在**考官提示词发出去之后**才出现的，不是点「开始」的一瞬间。这是刻意的：早一步录进去的是你等 ChatGPT 启动语音的那 9 秒沉默 |
| 有没有抢戏 | 录音指示**不该**把「我练完了」按钮的视觉主位抢走。整页仍然只有一个主行动 |
| 有没有多余的警告 | 一切正常时**不该**出现任何录音相关的提示卡片。出现了就把那段话一字不差抄下来 |
| 练完 | 到「训练记录」页，这一场那一行上应当有一个 **`waveform`（声波）小图标**，鼠标停上去显示「这一场有录音，点开可以回听」 |

**若整场都没出现「正在录音」：** 说明 `beginRecording()` 走的是 `.failed` 或 `.skippedByUser`。
`.failed` 时页面上一定会有一段中文说明（那是设计出来的，不许静默）；
**一段说明都没有、指示也没有**，就是开关没生效——回第 4 节确认开关真的是开的，
并在报告里注明「开关是开的但既没录音指示也没有任何提示」，这是缺陷。

## 7. 【计划 Step 4】回听

到「训练记录」页，**点那一行的卡片本身**（不是右边的垃圾桶图标）展开它。

| 看什么 | 判据 |
|---|---|
| **播放器位置** | 必须在逐字稿**上方**。反过来的话，一屏逐字稿会把播放器顶到看不见的地方 |
| 播放器长相 | 一张卡片，标题「**这一场的录音**」（`waveform` 图标）；一颗播放键（`play.fill` / `pause.fill`）、一条可拖动的进度条、右边「`当前时间 / 总时长`」 |
| 点播放 | **有没有声音？** 没有的话，卡片里应当出现一段中文说明（「这个录音文件打不开…」或「这条录音播不出来（系统拒绝了播放请求…）」）——**绝不能是一颗按下去没反应的播放键** |
| **总时长** | 是不是跟你实际练的时长接近？格式是 `MM:SS`，比如三分半是 `03:30`。**若显示 `00:00`**，去看 `Sources/IELTSCoachAudio/AACSegmentWriter.swift:99` 那行 `file = nil`（m4a 的索引在文件对象释放时才写出去），并在报告里写明 |
| 时间数字 | 播放过程中「当前时间 / 总时长」有没有左右抖动？必须没有（等宽数字） |
| 拖进度条 | 拖完滑块**不该自己弹回去**，声音要真的跳过去 |
| 收起再展开 | 点一下行卡片收起来，正在播的声音**必须立刻停**。还在响就是缺陷 |
| **录到了谁** | **仔细听：里面是不是只有你自己的声音？** |
| 键盘 | Tab 能不能走到播放/暂停、进度条、删除按钮？焦点环看得见吗？ |

> **Tab 走不到按钮时先别急着报缺陷。** macOS 默认只让 Tab 在文本框和列表之间走，
> 要先在「系统设置 › 键盘」里打开「**使用键盘导航在控制项之间移动焦点**」。
> 打开之后仍然走不到，才是本应用的问题。**报告里请注明你是在哪种设置下测的。**

### 关于「录到了谁」——这一条要如实记录

本工具**只采集麦克风、不采集系统音频**，所以录音里**不会有一条 ChatGPT 的音轨**。
但如果你用**外放**练，麦克风会从空气里把 ChatGPT 的声音一并收进去。**这不是 bug，是物理。**
设置页里那句「建议戴耳机练——用外放的话，麦克风会把 ChatGPT 的声音也一起录进去」说的就是这件事。

- [ ] **戴耳机**录一小段（第 6 节那一场就是），听感写进报告
- [ ] **外放**再录一小段（可以很短，说两句就点「我练完了」），听感写进报告
- [ ] 回答一个问题：**那句提示够不够？** 一个没看过这份文档的人，会不会外放练完才发现录进去一堆考官的声音？

## 8. 【计划 Step 5】插拔耳机 —— **本阶段最关键的一步**

前面所有测试证明的是「换设备时该干的事都干了」，**不是「真的插拔耳机时录音没丢」**。
真实设备切换的时序、`AVAudioEngineConfigurationChange` 到底发不发、发几次，只有真机能告诉你。

再练一场。**这一场不必真的答题，说什么都行**（数数、念课文都可以），目的是验录音。

  「IELTS Speaking Coach」打开即可。这个开关随时可改，不像第一次那样只弹一次
