### ⚠️ 一、演示数据的**题库是空的**，首页四格根本不会显示（头号阻断）

**这是本次准备工作里最重要的一条。**

`scripts/seed-demo-data.swift` 写出来的 `state.json` 里 `"questions": []`（实测：刚跑过一次，确认为空数组）。
而 `TodayView.body` 第一件事就是：

```swift
if app.state.questions.isEmpty {
    emptyBank            // 「题库还是空的」，整页只剩这一张导入引导
} else {
    statsRow             // ← 四格在这一支里
    …

```

题库空时**整页被导入引导接管**，四格、进度条、「改目标」按钮、「你的问题正在怎么变化」列表
**一个都不显示**。照计划 Task 11 Step 1 那三行命令做完，你会对着一句
「题库还是空的 / 没有题目，四条练习路线一条都走不通…」，然后以为 Task 8 白做了。

**它不是缺陷**：四格摆在 `else` 分支里是刻意的，因为四格的脚注写着「点下面的「开始练习」」，
