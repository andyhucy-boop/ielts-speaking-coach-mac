# IELTS Speaking Coach

一个 macOS 上的雅思口语陪练工具。它**替你操作 ChatGPT 桌面应用**：新建会话、点开语音、把考官提示词发过去、练完把复盘取回来存档。

你负责开口说，其余的它做。

[![下载 1.3.0](https://img.shields.io/badge/下载-1.3.0-5C51E8)](https://github.com/andyhucy-boop/ielts-speaking-coach-mac/releases/latest)

---

## 先说清三件事

这三条都会影响你能不能用，放在最前面，不藏在文档里。

1. **只能在 Apple 芯片（M1/M2/M3/M4…）的 Mac 上跑。** Intel 机双击会得到一句系统的英文提示——那不是签名问题，是发布包里没有 Intel 那份代码。
2. **没有经过 Apple 公证**，第一次打开会被系统拦一下，要手动放行（下面第 2 步）。
3. **需要「辅助功能」权限，也需要装新版 ChatGPT 桌面应用**（不是 ChatGPT Classic，Classic 没有语音）。

---

## 它到底做什么

- **开一场练习**：按学习计划、随机抽题、接着上次那道、或者自己挑一道；Part 1/2/3 都能单练或连练
- **练的时候**：它把考官提示词发给 ChatGPT 并开语音，你对着说；可选录音、可选记逐字稿
- **练完**：自动把复盘要回来、拆成「必须纠正的表达 / 更自然的说法 / 词汇升级 / 口语习惯 / 逐题逻辑 / 内容建议 / 逐题高分版」存档
- **然后**：错题进问题档案（同一个毛病犯过几场、最近有没有变少），生词进词汇本（可导出 Anki），复盘留下的**一个**单点目标进复训中心，下次带着它重练同一道题

一句设计原则贯穿全程：**每条消息都要说清「发生了什么 + 下一步做什么」**，不许静默失败。

## 它不做什么

- **不给你打分。** 工具从头到尾不预测雅思分数，也会把 ChatGPT 写出来的分数挡在总结之外——一个没有考官资质的模型给的数字，只会让人对着一个假指标练。
- **不联网上传。** 训练数据全部在本机，见下面「你的数据在哪」。
- **不自己更新自己。** 它会告诉你有新版本并打开发布页，不会下载或替换 App。

## 装

1. 从 [Releases](https://github.com/andyhucy-boop/ielts-speaking-coach-mac/releases/latest) 下载 zip，解开，把 `IELTS Speaking Coach.app` 拖进「应用程序」。

2. 双击。系统大概率会说「无法打开，因为 Apple 无法验证其是否包含恶意软件」。

   打开 **系统设置 › 隐私与安全性**，往下翻到「安全性」一节，会看到一行「已阻止使用 IELTS Speaking Coach」，点旁边的 **「仍要打开」**，再确认一次。

3. 第一次打开会请你给**辅助功能**权限。可以先跳过——跳过后是半自动模式：提示词自己粘、复盘自己按 ⌘C。

## 它拿辅助功能权限干什么

说清楚，因为这个权限本身很大：

它只用来**读和操作 ChatGPT 那一个窗口**——找到输入框、把提示词填进去、点发送、点语音按钮、练完把回复复制出来。不读你别的应用，不上传任何东西，也没有任何网络请求，除了「检查有没有新版本」那一次（只问 GitHub 要最新的版本号）。

想自己确认的话，驱动逻辑全在 [`Sources/ChatGPTBridge`](Sources/ChatGPTBridge)。

## 你的数据在哪

```
~/Library/Application Support/IELTS Speaking Coach/
```

题库、练习记录、逐字稿、录音、复盘原文都在这儿。**换电脑把这个文件夹整个拷过去就能接着用，备份就是拷贝它。** 换 App 包不会动它，所以更新直接替换 `.app` 即可。

卸载就是把 App 拖进废纸篓；这个文件夹要不要留，你自己决定。

---

## 题库要自己准备

**仓库里不含任何题库。** 你得自己导入一份（PDF / CSV / JSON / Markdown 都行），在「训练题库」页点「导入题库…」。

雅思口语题库多是有版权的商业整理稿，所以这里既不附带、也不替你去网上找。

## 从源码构建

需要 macOS 14 以上和 Xcode 命令行工具。

```bash
swift test          # 2246 条
./scripts/build-app.sh   # 打包、签名、装到 ~/Applications
```

打包脚本会先跑一遍测试再打包（`SKIP_TESTS=1` 可跳过），并用一张**固定的自签名证书**签名——固定是必须的：macOS 的辅助功能授权记的是签名的「指定要求」，ad-hoc 签名每次编译都变，用户就得反复回系统设置重新勾选。

## 给 Codex / Claude Code 用的 MCP 服务

`ielts-speaking-mcp` 这个可执行文件把题库、训练记录、复盘、问题档案以只读工具的形式暴露出来，配置见 [`codex/ielts-speaking-mcp.toml`](codex/ielts-speaking-mcp.toml)。
